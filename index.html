APT

curl -fsSL https://tuanapi.github.io/OpenAnime-Linux/openanime-repo.asc \
  | sudo tee /etc/apt/keyrings/openanime.asc >/dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/openanime.asc] \
  https://tuanapi.github.io/OpenAnime-Linux/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/openanime.list
sudo apt update && sudo apt install openanime

DNF

sudo rpm --import https://tuanapi.github.io/OpenAnime-Linux/openanime-repo.asc
sudo tee /etc/yum.repos.d/openanime.repo >/dev/null <<'EOF'
[openanime]
name=OpenAnime
baseurl=https://tuanapi.github.io/OpenAnime-Linux/rpm
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://tuanapi.github.io/OpenAnime-Linux/openanime-repo.asc
EOF
sudo dnf install openanime

pacman

curl -fsSL https://tuanapi.github.io/OpenAnime-Linux/openanime-repo.asc \
  -o /tmp/openanime-repo.asc
sudo pacman-key --add /tmp/openanime-repo.asc
printf 'F834BFA883FD8148B3D9D44A3DC4F7E104D352CA:6:\n' \
  | sudo gpg --homedir /etc/pacman.d/gnupg --import-ownertrust
sudo tee -a /etc/pacman.conf >/dev/null <<'EOF'

[openanime]
SigLevel = Required DatabaseOptional
Server = https://tuanapi.github.io/OpenAnime-Linux/pacman
EOF
sudo pacman -Syu openanime

Bölüm /etc/pacman.conf sonuna eklenir. /etc/pacman.d/openanime.conf içine yazmak işe yaramaz, çünkü Arch'un pacman.conf dosyasında Include = /etc/pacman.d/*.conf glob'u yoktur.

Diğer biçimler

AppImage, taşınabilir zip ve tar.gz sürümleri en son sürüm sayfasında yayımlanır. Ayrıca Arch için AUR paketleri (openanime kaynaktan derlenir, openanime-bin hazır) ve bir Nix flake mevcut.

Notlar

Paketler amd64 mimarisi için üretilir. Yeni sürümler yayımlandıkça havuzda birikir; eski sürümler sürüm numarası sabitlenerek kurulabilir. Depolar her dağıtımın kendi aracıyla üretilir — apt-ftparchive, createrepo_c ve repo-add — böylece üst veri kendi biçimindedir.
